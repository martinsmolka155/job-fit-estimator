   - ISCO 25XX, 26XX (ICT/digital design) → "it"

   - ISCO 261X (legal) → "legal"
   - ISCO 231X–235X (education) → "education"
   - ISCO 71XX–74XX (building, electrical, metalwork trades) → "trades"
   - ISCO 51XX–53XX (personal/protective/food services) → "services"

4. NORMALIZE seniority_level from title or context:
   - "Senior X" / "Sr. X" / "Seniorní" → "senior"

   - "Junior X" / "Jr. X" / "Juniorní" → "junior"

5. DETECT contractor/freelance pattern (set is_contractor=true if title or description contains):
   - "freelance", "freelancer", "contract", "contractor", "consultant", "konzultant"

6. DEDUPLICATE skills (case-insensitive). If "Python" and "python" both appear, keep one.

7. Skills with depth=null are perfectly OK — do NOT guess depth if uncertain.

8. For languages, return list of objects like: [{"name": "Czech", "level": "native"}]

9. Set is_management=true ONLY if the role explicitly meets at least one of:
   - Job title contains: "Manager", "Director", "Head of", "Lead" (when clearly supervisory), "VP", "C-level"
